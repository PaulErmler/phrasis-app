The politeness rows are now titled Casual, Polite and Formal, with each language's own form shown underneath (for example "e.g. du" or "🇮🇳 तुम · 🇨🇳 你"), so a course with several languages reads the same way everywhere. German now treats Sie as the polite level, like French vous. On the cards, the politeness chip reads "casual" or "formal" for every language except Japanese and Korean, which name their form (です・ます, 해요체).
